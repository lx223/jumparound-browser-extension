JumpAround Privacy Policy

Updated 3 November 2026

Local tab search

JumpAround reads open tab titles, URLs, favicons and access times, and browser history, to display and rank results. Searching happens locally. Search text, tab titles, URLs and browsing history are never included in analytics. Selecting a history result opens its URL. A search with no matching results can open Google with your query; that query is then handled by Google.

Optional usage analytics

Analytics is off by default. You can enable or disable it using the checkbox in the popup. When enabled and configured in the distributed build, JumpAround sends events to PostHog EU Cloud to understand opening methods and result selection.

Events contain a fixed product label (jumparound), the opening method (shortcut or browser action), a random identifier for each opening, selected result position, number of results, whether search text was present, keyboard or pointer selection, tab or history result type, timestamp, extension version, and a random installation identifier. We do not send the search text, tab titles, URLs, history entries, names or email addresses. We do not enable automatic click collection or session recordings. The analytics service receives network information such as your IP address when it receives requests.

Storage and controls

Theme preferences are stored locally. The analytics preference, random installation identifier and up to 100 pending analytics events are stored in extension storage. Pending events are retried after network failures. Disabling analytics deletes the local identifier and pending queue and stops future collection. Events already transmitted are not deleted by disabling analytics. Re-enabling creates a new installation identifier. Uninstalling removes extension-local storage.

Permissions

Tabs and history permissions support local search and navigation. Storage saves preferences and the optional analytics queue. Alarms retry queued events. Access to the PostHog ingestion host allows optional analytics delivery.

Third parties and questions

Optional analytics is processed by PostHog. Contact the maintainer through the extension support channels or source repository for privacy questions, including questions about previously transmitted events. Changes to these practices will be reflected here.
